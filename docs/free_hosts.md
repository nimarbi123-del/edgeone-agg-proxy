# 免费常驻托管方案对比（地毯式）

用途：替代 K40 手机跑一个 OpenAI 兼容 API 转发网关（7 个上游渠道、14 个模型、需 SSE 流式）。
硬需求：免费 / 无国外信用卡 / 免 ICP 备案 / 24x7 / 大陆访问比 Cloudflare 免费版快 / egress 能出墙。

**证据等级说明（重要）**
- 「已核实」= 本次会话查到官方文档原文并留了链接。
- 「未证实」= 凭既有认知填写，**尚未逐条核实**，用前必须自己点链接确认，不要当结论用。
- 本文件不编造数字：凡是记不清的数字，一律写「未证实」而不是瞎填。

## 一、结论（Top 3）

| 排名 | 方案 | 为什么 |
|---|---|---|
| 1 | **EdgeOne Makers 免费版 + Edge Functions**（本次采用） | 已核实：一键开通免费版、无需信用卡、免备案（代价是没有大陆节点，走香港/亚太）、300 万次/月、SSE 边收边发、官方有 AI 网关模板。且原链路是「CF 边缘→隧道→手机」双跳，这里变成单跳，去掉手机和隧道两段。 |
| 2 | 家里电脑自己跑（Tailscale/ZeroTier 直连） | 零成本、无第三方、点对点直连通常比走 CDN 边缘再回源更快。缺点：家里电脑必须 24x7 开机；只适合「自己几台设备用」。 |
| 3 | Cloudflare Workers/Pages（现状） | 免费、无信用卡、免备案，但大陆无节点且原方案叠了 Argo Tunnel 双跳 → 就是本次要换掉的原因。 |

## 六、本项目的选择逻辑

1. 目标是「手机退役 + 免备案 + 免费 + 比 CF 快」→ 只剩「海外边缘 serverless」这一档，其中 EdgeOne Makers 免费版额度最实在（300 万次/月）。
2. 少一跳就是提速：原链路 `客户端 → CF 边缘 → Argo 隧道 → K40 手机 → 上游`；新链路 `客户端 → EdgeOne 边缘(香港/亚太) → 上游`。
3. 如果 EdgeOne 实测还是慢，下一档是 Cloud Functions（可指定 `mainlandRegions: ["ap-beijing"]`，但**必须备案**）或家里电脑 + Tailscale 直连（无需备案、无需云）。
